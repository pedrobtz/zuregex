# Articles

### Guides

- [Move from base R and
  stringr](https://pedrobtz.github.io/zuregex/articles/from-base-r.md):

  The re\_\*() function for each base R and stringr function, and the
  places where the result differs.

- [Bound the work of a
  match](https://pedrobtz.github.io/zuregex/articles/limits.md):

  Set match, depth and heap limits so that a pattern or input you do not
  trust gives an error or an NA instead of a stall.

- [Link to zuregex from
  C](https://pedrobtz.github.io/zuregex/articles/c-api.md):

  Use zuregex’s bundled PCRE2 from another package’s C code, through
  LinkingTo and the zr\_\*() functions.

### Concepts

- [Design and
  motivation](https://pedrobtz.github.io/zuregex/articles/design.md):

  Why zuregex exists next to base R’s own PCRE2, how the cache and the
  threads work, what it was checked against, and what it leaves out.

- [Performance against base R and
  stringi](https://pedrobtz.github.io/zuregex/articles/benchmarks.md):

  How long zuregex takes for common tasks, next to base R’s perl = TRUE
  functions and stringi, and what the numbers do and do not show.
